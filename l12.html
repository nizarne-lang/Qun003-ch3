الدرس الثاني عشر · البند 3-5-6

تحليل المقدار الثلاثي بطريقة التجميع

عددان حاصل ضربهما ac ومجموعهما b — ثم تفكيك الحد الأوسط وتجميع الحدود مثنى مثنى.

أهداف الدرس
  • أن يجد الطالب العددين m, n بشرطَي الضرب والجمع.
  • أن يفكّك الحد الأوسط ويجمّع ويُخرج العامل المشترك.
  • أن يطبّق الحالتين الخاصتين a = 1 و a = −1 (ملاحظة 3-3).
  • أن يستعمل التعويض u للمقادير «ثلاثية الشكل» مثل x4 + 5x2 − 36.
  • أن يختار بين التجميع والمميّز بحسب المعاملات.

3-5-6 تحليل المقدار الثلاثي باستخدام طريقة التجميع (تفكيك الحد الأوسط)

طريقة المميّز تعمل دائماً، لكنها تمرّ بجذر تربيعي وكسور. أما التجميع فيبقى في الأعداد الصحيحة من أوله إلى آخره — وهو أسرع متى كانت المعاملات صحيحة.

الخطوات لتحليل a x2 + bx + c حيث a, b, c ∈ ℝ, a ≠ 0 وذلك عندما يكون Δ = b2 − 4ac ≥ 0 : 1) نبحث عن عددين m, n يحقّقان الشرطين:
m n = a c   و   m + n = b
2) نعيد كتابة الحد الأوسط: b x = (m + n)x = m x + n x.
3) نُجمِّع الحدود الأربعة في مجموعتين ونُخرج من كل مجموعة عاملها المشترك.
4) نكتب الناتج على صورة حاصل ضرب قوسين.
a x2 + bx + cاحسب a c و bابحث عن m, n : حاصل ضربهما a c ومجموعهما bفكّك b x إلى m x + n xجمّع الحدود مثنى مثنى وأخرِج العامل المشتركقوسان متماثلان ⇒ أخرجهما عاملاً مشتركاً
ملاحظة (3-3) — حالتان خاصتان تختصران العمل عندما a = 1 : نبحث عن m, n بحيث m n = c و m + n = b ، وعندها مباشرةً:
x2 + bx + c = (x + m)(x + n)
وعندما a = −1 : نبحث عن m, n بحيث m n = −c و m + n = b ، وعندها:
−x2 + bx + c = −(x − m)(x − n)
كيف تجد انظر إلى إشارة ac أولاً:
  • ac > 0 ⇒ العددان لهما الإشارة نفسها، وهي إشارة b.
  • ac < 0 ⇒ العددان مختلفا الإشارة، والأكبر مطلقاً إشارته إشارة b.
ثم اكتب أزواج عوامل |ac| وجرّب أيُّها يعطي المجموع المطلوب.
أيُّ الطريقتين؟ إن كان ac عدداً صحيحاً صغيراً فالتجميع أسرع. وإن تعذّر إيجاد m, n صحيحين، فالجذور غير نسبية ولا بد من المميّز (أو أن المقدار لا يُحلَّل أصلاً). والطريقتان تعطيان النتيجة نفسها دائماً.
كيف تكتب إجابتك في خانات التمارينالأُس بالعلامة ^ هكذا x^2 أو x^3، والضرب يُفهم من التجاور فتكتب 2x(x-3)، والكسر بالشَّرطة (x+1)/(x-2)، والجذر sqrt(2). ولا يهم ترتيب الحدود ولا شكل المقدار: يُقبل كل مقدار يساوي الإجابة جبرياً، فـ (x-1)(x+1) و x^2-1 سواء — إلا في أسئلة التحليل فيُشترط أن تكون الإجابة محلَّلة لا مفكوكة.
