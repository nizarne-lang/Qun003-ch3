الدرس الحادي عشر · البند 3-5-5

تحليل المقدار الثلاثي بطريقة المميّز

Δ = b2 − 4ac يخبرك قبل أن تبدأ: هل يقبل المقدار التحليل، وكم جذراً له — ثم يعطيك التحليل مباشرة.

أهداف الدرس
  • أن يحسب الطالب Δ بعد ترتيب المقدار على صورة a x2 + bx + c.
  • أن يحدّد الحالة الثلاثية ويكتب التحليل المناسب لها.
  • أن لا ينسى المعامل a أمام الأقواس.
  • أن يحوّل الجذور الكسرية إلى معاملات صحيحة بتوزيع a.
  • أن يربط Δ بعدد نقاط تقاطع المنحنى مع المحور الأفقي.

3-5-5 تحليل المقدار الثلاثي باستخدام طريقة المميّز

الطرائق السابقة تشترط شكلاً خاصاً (مربعين، مكعبين، عامل مشترك). أما المميّز فيعمل مع أي مقدار ثلاثي، ويخبرك سلفاً إن كان التحليل ممكناً أصلاً.

المميّز لتحليل المقدار الثلاثي P(x) = a x2 + b x + c حيث a, b, c ∈ ℝ, a ≠ 0 نبدأ بحساب العدد الحقيقي Δ :
Δ = b2 − 4ac
1) إذا كان Δ < 0 فإن المقدار غير قابل للتحليل.
2) إذا كان Δ = 0 فإن x1 = −b2a ويكون:
a x2 + b x + c = a(x − x1)2
3) إذا كان Δ > 0 فإن:
x1 = −b + √Δ2a   و   x2 = −b − √Δ2a
a x2 + b x + c = a(x − x1)(x − x2)
وعندما يكون Δ ≥ 0 يُسمّى x1 و x2 جذري أو صفري المقدار الثلاثي.
لا تنسَ المعامل الخطأ الأشهر هنا نسيان a أمام الأقواس. فـ 4x2 − 5x − 6 جذراه 2 و −34 ، والتحليل 4(x − 2)(x + 34) لا (x − 2)(x + 34). وللتحقق انظر إلى معامل x2 : لا بد أن يعود 4.
تنظيف الكسور إن ظهر جذر كسري، فوزّع a على القوس لتحصل على معاملات صحيحة:
4(x − 2)(x + 34) = (x − 2) × 4(x + 34) = (x − 2)(4x + 3)
وهذه الصورة أنظف، وكلتاهما صحيحة.
رتّب المقدار أولاً المميّز يفترض الترتيب a x2 + b x + c. فإذا أُعطيتَ 2 + x2 + x فأعِد ترتيبه x2 + x + 2 قبل قراءة a, b, c ، وإلا أخذتَ a = 2 خطأً.
كيف تكتب إجابتك في خانات التمارينالأُس بالعلامة ^ هكذا x^2 أو x^3، والضرب يُفهم من التجاور فتكتب 2x(x-3)، والكسر بالشَّرطة (x+1)/(x-2)، والجذر sqrt(2). ولا يهم ترتيب الحدود ولا شكل المقدار: يُقبل كل مقدار يساوي الإجابة جبرياً، فـ (x-1)(x+1) و x^2-1 سواء — إلا في أسئلة التحليل فيُشترط أن تكون الإجابة محلَّلة لا مفكوكة.
